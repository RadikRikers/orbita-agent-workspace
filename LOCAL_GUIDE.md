# Орбита — личное рабочее место агентов

## Быстрый запуск

1. Установите Python 3.10 или новее: https://www.python.org/downloads/ . В Windows включите Add Python to PATH.
2. Распакуйте весь архив. Windows: запустите START_WINDOWS.bat. macOS/Linux: откройте терминал в этой папке и выполните `python3 server.py`.
3. Откроется http://127.0.0.1:8765 . Не закрывайте окно запуска.
4. В Настройках сохраните API-ключ Hubris. Нажмите Проверить. Выберите рабочую папку и нажмите Применить.
5. В разделе Команда агентов задайте ID моделей из каталога Hubris. Начальное назначение — openai/gpt-4o-mini для всех ролей. Требуется поддержка вызова инструментов (tools/function calling). Каталог содержит и модели, которые для агентов не подходят; проверьте возможности выбранной модели на https://hubris.pw/models .
6. Добавьте материалы, опишите задачу и разрешите нужные доступы. Стоимость зависит от выбранных моделей и числа запросов; каждый этап тарифицируется Hubris.

## Возможности

- Пять ролей: координатор → параллельные исследователь и аналитик → редактор → проверяющий. Если проверяющий запросил исправления, редактор делает одну доработку; отсутствие повторной независимой проверки явно указано в результате.
- Режим одного агента с инструментами для простых задач.
- Список файлов, поиск текста в файлах, чтение TXT/MD/CSV/TSV/JSON, кода, DOCX и XLSX. Для XLSX извлекаются значения ячеек; формулы не пересчитываются, форматирование не переносится.
- CSV: строки, дубли, пустые значения, уникальные значения, суммы, средние, минимум и максимум числовых столбцов. Первая строка считается заголовком. Текст с валютами и единицами измерения автоматически в числа не преобразуется.
- Публичный веб-поиск DuckDuckGo или Brave Search API, чтение HTML-страниц по ссылке. DuckDuckGo может блокировать автоматические запросы; при отсутствии результатов приложение выдаёт ошибку, а не выдумывает ссылки. Страницы за авторизацией, CAPTCHA и часть сайтов с JavaScript не поддерживаются.
- Создание новых MD/TXT/CSV/JSON/HTML в outputs; существующие файлы не перезаписываются. Генерация оформленных DOCX/XLSX/PDF, OCR, произвольное выполнение Python/команд и управление экраном не реализованы.
- Журнал этапов, остановка, копирование и экспорт результата, история последних 30 задач в localStorage текущего браузера. Истории облачной и локальной вкладок независимы. Для переноса используйте экспорт; импорт истории не реализован.

## PDF

Для текстовых PDF установите пакет:

```
python -m pip install pypdf
```

или `python3 -m pip install pypdf`. Пакет необязательный, все остальные функции работают без него. Для сканов нужен OCR, он не подключён.

## Доступ и хранение

Сервер слушает только 127.0.0.1. Не публикуйте его через прокси или туннель. Проверяются Host, Origin и временный токен сессии. Сайт в интернете не обращается к локальному серверу: локальное приложение открывает тот же интерфейс на вашем компьютере.

Выбранная рабочая папка доступна агентам целиком при включённом доступе «Файлы». Прикрепление конкретных файлов помогает выбрать материалы, но не ограничивает чтение остальной рабочей папки. Не выбирайте весь диск или домашнюю папку; используйте папку проекта. Скрытые файлы, распространённые ключевые файлы и выход через символические ссылки блокируются. Это не средство гарантированного обнаружения всех секретов в произвольных документах.

Тексты, которые агенты прочитали для задачи, отправляются через Hubris выбранному поставщику модели. Поисковые запросы передаются поисковой системе. Ключи хранятся локально в `~/.orbita/settings.json`; браузер их обратно не получает. В Linux/macOS выставляются права 0600. В Windows файл защищён обычными правами вашей учётной записи; шифрование ключей ОС не реализовано. История содержит тексты результатов, хранится в браузере и удаляется в Настройках.

Переключатели «Интернет», «Файлы» и «Создание файлов» проверяются на сервере. Разрешение создания файлов действует только на новую запись в outputs. Удаление и изменение исходников не предусмотрены.

## Ограничения и устранение ошибок

- Для чтения одного файла — до 32 МБ. Извлечение документа — до 160 000 символов, один результат инструмента — до 30 000 символов. PDF — до 100 страниц. XLSX — до 3000 строк на лист. Список папки — до 1000 файлов; поиск текста — по первым 150 файлам. Для больших массивов разделите материалы на части.
- По умолчанию максимум 24 вызова моделей на задачу, до 2500 выходных токенов на вызов, до 6 шагов на агента. Лимиты настраиваются. Они ограничивают объём работы, а не фиксированную стоимость в рублях. Стоимость показывается, только если API вернул usage.cost (в копейках по контракту Hubris); окончательные списания смотрите в Hubris.
- Сеть, ключ, лимиты и отсутствие поддержки tools приводят к видимым ошибкам. Проверка ключа читает каталог; доступность конкретной модели проверяется при запуске задачи.
- Остановка не отменяет уже отправленный запрос к API. Он может завершиться и тарифицироваться. После ответа новые шаги не запускаются. В памяти локального сервера задачи сохраняются до его перезапуска; завершённые результаты копируются в историю браузера.
- Чтобы использовать другой порт: задайте переменную ORBITA_PORT перед запуском. Например PowerShell: `$env:ORBITA_PORT="8766"; py -3 server.py`. Для переноса папки настроек можно задать ORBITA_DATA_DIR.
- Диалог папки использует tkinter. Если он недоступен, введите абсолютный путь вручную и нажмите Применить.
- Если Python не найден в Windows, переустановите его с Add Python to PATH. Если порт занят, закройте предыдущую Орбиту или смените порт.
- Ни ключи, ни реальные вызовы платных моделей при подготовке приложения не использовались. Сетевые интеграции требуют проверки с вашим ключом и вашим доступом в интернет. Модульные и интеграционные проверки используют подмену внешнего API.

## Исходный код

`server.py` — локальный HTTP/API-сервер и координация агентов. `index.html` — интерфейс. Обязательных внешних Python-зависимостей нет. Шрифт Golos Text загружается из Google Fonts; при отсутствии сети используется системный шрифт.
