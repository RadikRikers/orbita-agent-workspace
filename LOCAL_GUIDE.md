# Орбита 1.1: Chrome DevTools MCP

## Для чего нужен локальный запуск

GitHub Pages отдаёт интерфейс сайта. Доступ к Chrome и рабочей папке выполняет приложение на вашем компьютере. Оно открывает тот же интерфейс на http://127.0.0.1:8765 и подключает официальный Chrome DevTools MCP через stdio. Модели вызываются через API Hubris.

## Подключение

1. Установите Python 3.10+: https://www.python.org/downloads/ . В Windows включите Add Python to PATH.
2. Установите Node.js LTS: https://nodejs.org/en/download . Пакету MCP нужны Node 20.19+, 22.12+ или более новые версии; используйте поддерживаемую LTS-ветку. После установки перезапустите окно Орбиты, чтобы обновился PATH.
3. Откройте Google Chrome 144 или новее с профилем, в котором уже выполнены нужные входы.
4. В адресной строке Chrome откройте `chrome://inspect/#remote-debugging` и включите удалённую отладку. Эта настройка нужна для штатного режима autoConnect.
5. Распакуйте архив приложения целиком. Windows: `START_WINDOWS.bat`. macOS/Linux: `python3 server.py`. Если Chrome не найден автоматически, вручную откройте в нём http://127.0.0.1:8765 . Другой браузер автоматически не запускается.
6. В Настройках локальной Орбиты сохраните ключ Hubris и нажмите Проверить. Укажите модели, поддерживающие инструменты. Для работы со скриншотами модель должна поддерживать изображения.
7. Откройте раздел Chrome и MCP → Подключить Chrome. При первом подключении npx загрузит официальный пакет из npm. Разрешите входящее подключение в диалоге Chrome. Статус «Chrome подключён» появляется только после получения списка вкладок, а не просто запуска процесса MCP.
8. По кнопке Показать вкладки проверьте подключение. Поставьте задачу на главной странице.

Орбита запускает MCP с `--autoConnect --no-usage-statistics --no-performance-crux`. Отдельный профиль Chrome не создаётся, DevTools-порт в интернет не публикуется. Ручное копирование cookies или паролей не требуется. После подключения Chrome может показывать баннер управления автоматизированным ПО — это штатное поведение Chrome.

## Как агенты пользуются браузером

Всем агентам доступен один Chrome. Чтобы избежать конфликтов выбранной страницы и устаревших uid, этапы с браузером выполняются последовательно. Каждый агент начинает с актуального списка вкладок, получает снимок нужной страницы и после действия проверяет новое состояние. Координатор планирует, исследователь собирает источники, аналитик сопоставляет данные, редактор готовит результат, проверяющий оценивает его. При замечаниях редактор делает одну доработку; повторная независимая проверка после неё не заявляется.

Через MCP доступны список/открытие/выбор/закрытие вкладок, переходы, текстовые снимки и скриншоты, клики, ввод, формы, ожидание и загрузка разрешённых файлов. Схемы инструментов получаются от установленного MCP-сервера при подключении. Профилирование, установка расширений, сетевые заголовки, произвольный JavaScript и чтение хранилищ авторизации агентам не предоставляются. Полноценная работа с сайтами выполняется через пользовательский интерфейс Chrome. Не каждый сайт допускает автоматизацию; при CAPTCHA или новом входе агент должен сообщить о необходимости участия пользователя.

Режим «Один агент» сокращает число обращений к модели. Поиск в отдельном разделе открывает запрос в вашем Chrome; кнопка Передать команде создаёт задание на изучение выдачи и источников. Прямые HTTP-поиск и чтение сайтов на стороне Python отключены.

## Файлы и результаты

Переключатель Файлы разрешает чтение рабочей папки целиком, а не только прикреплённых файлов. Добавленные через интерфейс файлы копируются в inbox. Доступны TXT, MD, CSV, TSV, JSON, DOCX, XLSX и текст исходного кода. Для текстовых PDF установите `python -m pip install pypdf`; OCR сканов не подключён. XLSX извлекается как значения ячеек: формулы не пересчитываются и оформление не переносится.

CSV анализируется программно: число строк, дубли, пустые и уникальные значения, суммы, средние, минимум и максимум числовых столбцов. Первая строка считается заголовком. Валюты и единицы измерения внутри ячеек автоматически в числа не преобразуются.

Переключатель Создание файлов разрешает запись новых MD/TXT/CSV/JSON/HTML в outputs. Исходники не перезаписываются. Для отправки файла на сайт через Chrome нужен доступ Файлы; путь проверяется относительно рабочей папки, файл должен существовать и быть не более 32 МБ.

## Данные и ключи

Входы в сайты хранятся в профиле Chrome. Орбита не копирует cookies в настройки. Ключ Hubris хранится локально в `~/.orbita/settings.json`, обратно браузеру не выдаётся. В Linux/macOS устанавливаются права 0600; в Windows используются обычные права вашей учётной записи. Шифрование хранилищем ОС не реализовано.

Содержимое страниц и файлов, которые агент использует для задачи, передаётся через Hubris выбранному поставщику модели. Снимки экрана передаются только при вызове соответствующего инструмента. История результатов и инструкции сохраняются в localStorage браузера; история облачной и локальной вкладок независима. Ключи, входы Chrome и документы пользователя в GitHub не загружаются.

Сервер Орбиты слушает только 127.0.0.1 и проверяет Host, Origin и временный токен сессии. Не публикуйте его через туннели или прокси. Скрытые файлы, распространённые ключевые файлы и выход через символические ссылки блокируются; это не гарантирует обнаружение всех секретов внутри произвольных документов.

## Лимиты и остановка

По умолчанию до 48 запросов моделей на задачу, 18 шагов одного агента и 2500 выходных токенов на запрос. Предыдущие пользовательские настройки сохраняются; при необходимости измените лимиты. Эти ограничения не задают фиксированную стоимость в рублях. Расход зависит от модели и объёма страниц. Стоимость показывается, только если Hubris вернул usage.cost; окончательные списания смотрите в кабинете Hubris.

До 32 МБ на локальный файл; извлечение до 160 000 символов документа, до 40 000 символов одного ответа инструмента. PDF — до 100 страниц; XLSX — до 3000 строк на лист; список папки — до 1000 файлов; поиск по содержимому — первые 150 файлов. Для больших массивов разделите материалы на части.

Остановка передаёт уведомление отмены MCP и прекращает новые шаги. Уже отправленный клик, отправка формы или запрос к модели могут завершиться; запрос к модели может тарифицироваться. Нажимайте Отключить после завершения или остановки задачи. При выходе из Орбиты MCP-процесс завершается; подключение текущего Chrome прекращается.

## Если не подключается

- Не найден npx: установите Node.js LTS и перезапустите Орбиту.
- Подключение зависло: проверьте диалог разрешения Chrome, текущий профиль и настройку `chrome://inspect/#remote-debugging`. Первая загрузка npm требует интернета и может занять до двух минут.
- Chrome старее 144: обновите Google Chrome. Подключение к Яндекс Браузеру или другим Chromium-браузерам не заявляется.
- Ошибка модели HTTP 400: проверьте ID модели в Hubris и поддержку tools/function calling; для скриншотов нужна vision-модель.
- Порт занят: закройте предыдущую Орбиту или задайте ORBITA_PORT. Например PowerShell: `$env:ORBITA_PORT="8766"; py -3 server.py`.
- Диалог папки не появился: введите абсолютный путь вручную и нажмите Применить.
- После изменения подключения во время задачи приложение попросит дождаться завершения или остановить задачу. Это защищает очередь действий в общем браузере от случайного переключения подключения.

У приложения нет доступа к рабочему столу и произвольным командам ОС. Работа с сайтами выполняется только через подключённый Chrome.
