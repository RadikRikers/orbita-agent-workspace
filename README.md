# Орбита — рабочее место агентов

Веб-интерфейс команды ИИ-агентов с моделями Hubris и локальным доступом к рабочей папке.

## Структура

- `index.html`, `favicon.svg` — готовый сайт для GitHub Pages; сборка и Node.js не требуются.
- `server.py`, `START_WINDOWS.bat`, `START_MAC_LINUX.sh` — локальное приложение на Python 3.10+, обязательных внешних пакетов нет.
- `test_orbita.py` — проверки чтения файлов, расчётов, доступов, API и взаимодействия агентов.

## Запуск на компьютере

Скачайте [orbita-local.zip](orbita-local.zip), распакуйте архив и запустите `Orbita/START_WINDOWS.bat`. Для macOS/Linux выполните `python3 server.py` в папке `Orbita`.

Приложение откроется на http://127.0.0.1:8765 . В настройках укажите свой API-ключ Hubris и рабочую папку. Ключи в репозитории отсутствуют. Дополнительные настройки и ограничения описаны в [инструкции](LOCAL_GUIDE.md).

## Публикация через GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`, нажмите Save. GitHub разместит веб-интерфейс и архив локального приложения. Новые коммиты в `main` автоматически обновляют сайт.

GitHub Pages раздаёт статические файлы: сервер Python, вызовы моделей и доступ к папкам работают в локальном приложении. Сайт Pages общедоступен. Файлы пользователя и его ключи в Pages не загружаются.

## Возможности

Пять агентов: координатор, исследователь, аналитик, редактор и проверяющий. Исследователь и аналитик работают параллельно; предусмотрены проверка и один цикл доработки. Доступны чтение TXT/CSV/DOCX/XLSX, вычисление статистики CSV, веб-поиск, чтение публичных страниц, создание новых результатов, журнал и экспорт. PDF поддерживается после установки `pypdf`. Модели тарифицируются Hubris по вашему ключу.

## Проверки

```sh
python3 -m unittest test_orbita -v
```

Интеграция агентов проверяется с подменой внешнего API. Реальные запросы к платным моделям требуют вашего ключа.
