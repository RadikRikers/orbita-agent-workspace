# Орбита — агенты в твоём Chrome

[Открыть сайт](https://radikrikers.github.io/orbita-agent-workspace/) · [Скачать локальное приложение](orbita-local.zip)

Орбита связывает модели Hubris с текущим Chrome через официальный **Chrome DevTools MCP**. Входы на сайты остаются в профиле Chrome; отдельные логины в Орбиту для каждого сайта не нужны.

## Запуск

1. Установите Python 3.10+ и Node.js LTS (совместимы Node 20.19+, 22.12+ или более новые ветки по требованиям MCP). Откройте Google Chrome 144+ с нужным профилем и выполненными входами.
2. Скачайте `orbita-local.zip`, распакуйте весь архив. Windows: запустите `START_WINDOWS.bat`. macOS/Linux: выполните `python3 server.py` в распакованной папке. Окно запуска оставьте открытым.
3. В Chrome откройте `chrome://inspect/#remote-debugging` и включите удалённую отладку.
4. В локальной Орбите добавьте свой API-ключ Hubris в Настройках. Откройте **Chrome и MCP → Подключить Chrome**. Первое подключение загружает `chrome-devtools-mcp@latest` из npm. Разрешите подключение в штатном диалоге Chrome.
5. Когда появится «Chrome подключён», опишите задачу на главной странице. Переключатель **Chrome MCP** разрешает агентам использовать браузер. В разделе команды можно выбрать модель каждому агенту; модель должна поддерживать вызовы инструментов. Для снимков экрана нужна поддержка изображений.

GitHub Pages размещает интерфейс и архив. MCP и агенты работают в локальной Орбите на компьютере. Подробная инструкция: [LOCAL_GUIDE.md](LOCAL_GUIDE.md).

## Как работает команда

Координатор составляет план. Исследователь, аналитик, редактор и проверяющий работают с общим Chrome по очереди. Они получают список вкладок, читают свежие снимки страниц, переходят по ссылкам, заполняют формы и проверяют результаты действий. При замечаниях предусмотрен один цикл доработки. Для простых задач есть режим одного агента.

Взаимодействие с внешними сайтами выполняется только через Chrome DevTools MCP. Прямые HTTP-инструменты поиска и чтения страниц отключены. Чтение выбранной рабочей папки, анализ CSV и создание новых файлов результатов остаются отдельными локальными инструментами с переключателями доступа. Загрузка файла на сайт через Chrome допускается только из рабочей папки и при включённом доступе «Файлы».

## Состав

- `index.html`, `favicon.svg` — интерфейс, готовый для GitHub Pages.
- `server.py` — локальный сервер, интеграция Hubris и координация агентов.
- `chrome_mcp.py` — локальный клиент MCP по stdio, управление подключением текущего Chrome.
- `chrome-devtools.mcp.json` — пример подключения официального MCP из другого клиента.
- `orbita-local.zip` — приложение для скачивания с сайта.
- `test_orbita.py`, `test_chrome_mcp.py` — проверки локальных инструментов и протокола MCP.

Публикация Pages настроена из ветки `main`, папка `/ (root)`. Новые коммиты в `main` обновляют сайт автоматически.

## Проверка

```sh
python3 -m unittest test_orbita test_chrome_mcp -v
```

Проверки MCP используют отдельный тестовый stdio-сервер без запуска браузера; проверки моделей используют подмену внешнего API. Подключение к реальному Chrome и платным моделям нужно проверить на своём компьютере со своим ключом. Проверка протокола не означает, что все сайты позволят автоматизацию: CAPTCHA, новый вход и часть интерфейсов требуют участия пользователя.
