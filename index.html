Chrome и MCP

Агенты работают в твоём Chrome и используют уже выполненные входы на сайты.

CHROME DEVTOOLS MCP

Chrome ещё не подключён

Подключение выполняется локальным приложением через официальный Chrome DevTools MCP.

Входы остаются в браузере. Читать пароли и переносить cookies в Орбиту не требуется. Модели получают содержимое страниц, которые агенты открывают для задачи.

Подключение текущей сессии

1
Запусти Орбиту на компьютере

Нужны Python 3.10+ и Node.js LTS ↗. Орбита откроется в Google Chrome.

2
Разреши отладку в Chrome 144+

Открой в адресной строке Chrome:

chrome://inspect/#remote-debugging

Включи доступ к удалённой отладке. Нужные сайты должны быть открыты в этом профиле Chrome.

3
Нажми «Подключить Chrome»

При первом запуске загрузится официальный пакет MCP. Разреши подключение в появившемся диалоге Chrome.

Один браузер — одна очередь действий. Агенты передают результаты друг другу и проверяют состояние страницы после действий.

Орбита → локальный MCP-клиент → Chrome DevTools MCP → твой Chrome. Модели и роли — через Hubris. Удалённый порт Chrome в интернете не публикуется.

Команда агентов

Одна задача, разные роли. Модель можно назначить каждому агенту.

Модели работают через Hubris. Доступ к сайтам — через Chrome DevTools MCP на компьютере.
Координатор составляет план. Исследователь, аналитик, редактор и проверяющий работают с общим Chrome по очереди, чтобы не переключать друг другу страницы. При замечаниях предусмотрен один цикл доработки. В режиме «Один агент» браузером управляет редактор. Без доступа к Chrome независимые этапы могут выполняться параллельно.

Поиск в Chrome

Запрос откроется в твоём Chrome с текущими входами. Команда сможет изучить результаты.

Поиск выполняется в Chrome через DevTools MCP. Подключи браузер в разделе «Chrome и MCP».

Твой компьютер

Агенты читают только выбранную рабочую папку. Новые файлы создаются в подпапке outputs.

Выбор папки даёт агентам доступ ко всем обычным файлам внутри неё при включённом переключателе «Файлы».
Исходники сохраняются. Результаты записываются в новые файлы. Сайтами агенты управляют через Chrome DevTools MCP. Произвольные команды и управление другими программами не подключены.

Правила и лимиты

Применяются к новым задачам. Лимит вызовов включает обращения всех агентов и их инструментов.

Шаг — запрос к модели; один ответ может содержать несколько действий в Chrome.
Это ограничение объёма ответа, не фиксированный бюджет в рублях. Расход зависит от модели и объёма входных данных.

Хранение и доступ

История результатов и инструкции сохраняются в браузере. Файлы и настройки ключей — на компьютере в локальном приложении. Входы на сайты остаются в Chrome.

Тексты, которые агент читает для задачи, отправляются через Hubris выбранному поставщику модели. Интернет-поиск передаёт запрос поисковой системе.

Приложение слушает только 127.0.0.1. GitHub Pages служит стартовой страницей. Локальная вкладка Орбиты связывает Hubris и Chrome DevTools MCP. Подключение к Chrome разрешается его штатным диалогом.
